# 🎬 局域网视频站

电脑上启动一个小服务，手机浏览器打开地址即可在线播放电脑里的视频。只需 Python（3.10+），无需安装任何第三方库。

## 启动

**方式一（推荐）：** 双击 `start.bat`

**方式二：** 在本目录打开终端执行

```bash
python video_server.py
```

启动后会打印访问地址，例如：

```
  手机访问（手机和电脑连同一个 Wi-Fi）:
      ➜  http://192.168.1.100:8080/
```

手机浏览器打开这个地址即可。电脑上也会自动打开页面。

> ⚠️ 第一次启动如果 Windows 弹出防火墙询问，请**勾选"专用网络"并点"允许访问"**，否则手机连不上。

## 添加多个视频目录（三种方式任选）

1. **网页**：首页点「＋ 添加视频目录」，输入文件夹路径，如 `E:\新建文件夹\3fui`
2. **控制台**：启动后直接在命令行窗口粘贴文件夹路径回车
3. **启动参数**：`python video_server.py --dir D:\电影`（可多次使用）

目录列表保存在 `library.json`，重启后仍生效。移除目录（网页 ✕ / 控制台 `rm 别名`）不会删除文件。

**控制台命令**：直接粘贴路径 = 添加 · `ls` 列表 · `rm 别名` 移除 · `q` 退出 · `help` 帮助

## 拖动进度条为什么能秒拖？

很多下载来的 mp4 索引（moov）在文件尾部，浏览器必须顺序读完才能定位任意时间点。
本服务在内存里**实时把字节流重排**成索引在前的顺序再发给手机——不生成缓存文件、
不转码、不改原文件、几乎不占 CPU，也没有任何硬盘开销。

## 常用参数

| 命令 | 说明 |
| --- | --- |
| `python video_server.py` | 默认播放本目录下的「视频」文件夹 |
| `python video_server.py --dir 目录` | 启动时添加目录（可多次使用） |
| `python video_server.py --port 9000` | 换端口（默认 8080，被占用会自动 +1） |

## 功能

- ⭐ 收藏夹：默认收藏夹 + 自建收藏夹（不限数量），播放页一键收藏、可同时勾选多个；视频改名自动迁移，源文件删除自动清理，数据存 `favorites.json` 所有设备共享
- 📱 手机优先的深色界面（白天/黑夜模式一键切换，桌面宽屏自适应双列播放页）
- 📚 多媒体库：多目录管理 + 文件夹浏览 + 面包屑导航 + 全库搜索
- ▶️ 在线播放，进度条任意位置秒拖（HTTP Range + 内存虚拟索引重排）
- ✏️ 播放页可直接重命名视频，磁盘文件同步改名，播放进度跟着迁移、播放不中断
- 🖼️ 缩略图按视频原始比例居中裁剪，时长角标、观看进度条；三级缓存（浏览器本地 → 服务器磁盘 `.thumbcache` → 现场生成），换设备/重启服务/清浏览器缓存都不用重等
- 📁 文件夹统一宫格卡片样式（名称 + 视频数量角标）
- ⏯️ 自动记忆每个视频的播放进度（播放中每 5 秒落盘）；「从头播放」「本文件夹更多」宫格快捷切换
- 📲 播放中视频吸顶，边看边逛；暂停后向下滑动时视频区自动收起，点「继续播放」一键回到视频
- 📂 支持中文文件名和特殊字符

## 便携版

**便携版 zip 请到 [Releases](https://github.com/AMGHCTY/lan-video-site/releases/latest) 页面下载**（约 11 MB），自带 Python 运行时，**任何 Windows 电脑解压即用**：解压 → 双击「启动视频站.bat」。目标电脑无需安装 Python。

`portable/` 目录是便携包的打包配置（启动脚本与使用说明），打包方式：将 `video_server.py` + `portable/` 内文件 + Python 3.13 嵌入式运行时（python/）组合压缩即可。

## 说明

- 手机和电脑必须连在**同一个局域网**（同一个路由器 / 同一个 Wi-Fi）。
- 浏览器能直接播放的格式主要是 **mp4 / webm / mov**；mkv、avi、wmv 等格式能否播放取决于手机浏览器，多数不支持。
- 服务只在局域网内可访问，不会暴露到公网；同一网络内的任何人都能打开并添加目录，请勿在公共网络使用。
