# 🎬 局域网视频站

电脑上启动一个小服务，手机/平板/其他电脑用浏览器打开地址即可播放电脑里的视频——无需安装任何 App。
只依赖 Python（3.10+）标准库；搭配 ffmpeg 后可播放**任意格式**并自动用显卡硬编加速。

当前版本 **v1.2.0**（安全加固 + IP 白名单 + 播放记录 + 播放设置面板）。

## 启动

**方式一（推荐）：** 双击 `start.bat`

**方式二：** 在本目录打开终端执行

```bash
python video_server.py
```

启动后会打印访问地址，例如：

```
  手机访问（手机和电脑连同一个 Wi-Fi）:
      ➜  http://192.168.1.100:8080/
```

手机浏览器打开这个地址即可。电脑上也会自动打开页面。

> ⚠️ 第一次启动如果 Windows 弹出防火墙询问，请**勾选"专用网络"并点"允许访问"**，否则手机连不上。

## 添加视频目录（三种方式任选）

1. **网页**：首页点「＋ 添加视频目录」，输入文件夹路径，如 `E:\新建文件夹\3fui`——**路径不存在会自动创建**
2. **控制台**：启动后直接在命令行窗口粘贴文件夹路径回车（同样自动创建）
3. **启动参数**：`python video_server.py --dir D:\电影`（可多次使用）

目录列表保存在 `library.json`，重启后仍生效。移除目录（网页 ✕ / 控制台 `rm 别名`）不会删除文件。

### 控制台命令

| 命令 | 说明 |
| --- | --- |
| 粘贴路径回车 | 添加该文件夹为播放目录（不存在会自动创建） |
| `ls` | 查看当前播放目录列表 |
| `rm 别名` | 移除某个目录（不删除文件） |
| `port 端口号` | 运行中切换监听端口（如 `port 9000`，旧端口立即失效）；新端口被占用会自动退回原端口 |
| `allow 规则` | 设置 IP 白名单，如 `allow 192.168.31.0/24`、`allow 127.0.0.1,10.0.0.0/8`；支持 CIDR 与单个 IP，逗号/空格分隔。`allow` 不带参数查看当前规则，`allow off` 清空（留空 = 放行所有 IP） |
| `history` | 查看播放记录条数；`history clear` 清空全部播放记录 |
| `thumb` | 给所有视频生成缩略图（后台跑，`thumb stop` 可中断）；缩略图平时"浏览到才生成"，这个命令一次性补齐 |
| `stat` | 状态：目录、视频数、缓存占用 |
| `du` | 磁盘占用：各缓存目录 + 每个播放目录的视频总大小 |
| `search 关键词` | 在所有目录里按文件名搜索视频 |
| `dupes` | 按文件大小找疑似重复的视频 |
| `qr` | 把手机访问地址生成二维码（终端显示 + 弹出图片，手机扫码直连） |
| `cc` | 清空缩略图/转码/字幕缓存与预热记录（浏览网页时自动重建） |
| `warm` | 立即预热一遍全部目录（降低首次打开延迟） |
| `passwd` | 查看/设置/关闭网页访问密码（`passwd 新密码` / `passwd off`） |
| `open` | 打开网页界面 |
| `q` | 停止服务并退出 |
| `help` | 显示帮助 |

> 除 `qr` 命令需要 `pip install segno` 生成二维码外，其余功能只依赖 Python 标准库。

## 播放是怎么工作的

- **能直接播的（mp4/webm/mov 等）**：原生流式播放。很多下载来的 mp4 索引（moov）在文件尾部，
  本服务在**内存里实时把字节流重排**成索引在前的顺序再发出去——不写缓存文件、不改原文件，
  进度条任意位置秒拖。
- **浏览器播不了的（AVI/TS/WMV/MKV/MPEG4/部分 HEVC 等）**：自动用 ffmpeg **实时转码推流**——
  输出分片 MP4 直接流向浏览器，点开即播，不用等整片转完。编码器自动探测
  **NVIDIA NVENC / Intel QSV / AMD AMF** 硬件加速，都没有则回退 CPU x264；输出限制 1080p 保证转码快于播放。
- **转码流的拖动**：拖动进度条 = 从新位置重启 ffmpeg（硬编约 1~2 秒落位）；±3 秒内的小拖动在缓冲内直接跳。
- **兼容模式**：极少数设备解不出画面（只有声音没有图像）时，播放页会自动切换成强制转码。
- HEVC/H.265 依赖设备硬解：支持就直连播放（零转码），不支持自动转码。

## 功能

- 📚 多目录媒体库：文件夹浏览（自动取首个视频当封面）+ 面包屑导航 + 全库搜索 + 排序（名称/最新/最大/最长）
- ⭐ 收藏夹：默认收藏夹 + 自建分类，可同时勾选多个；改名自动迁移、源文件删除自动清理
- ✏️ 播放页直接重命名视频，磁盘文件同步改名，进度跟随、播放不中断
- 🗑️ 批量管理：文件夹页点「管理」多选视频，一键删除（同步清收藏与进度）；控制台 `dupes` 可按大小查重复
- 🖼️ 缩略图按原始比例居中裁剪（竖屏不变形）+ 时长角标 + 观看进度条；
  三级缓存：浏览器 IndexedDB → 服务器 `.thumbcache` → 服务端 ffmpeg 现场截帧（一次生成永久缓存）。
  缩略图默认"浏览到才生成"，想一次补齐全部视频的封面就在控制台敲 `thumb`
  （后台跑、可 `thumb stop` 中断，已存在的直接跳过）
- ▶️ **续播跨设备同步**：进度存在服务器 `progress.json`，手机看到一半、电脑打开接着看；
  首页「播放记录」一排没看完的视频，点卡片直接从上次位置续播；源文件被删/改名的记录会标灰并自动清理，
  也可点「清空记录」或控制台 `history clear` 一次性清掉
- 📋 **播放记录页**：点首页「▶ 播放记录」标题进入，列表形式显示最近 100 条
  （100 只是这一页的显示上限，`progress.json` 里仍保留全部记录，服务端上限 2000 条）；
  每条带缩略图、时长、观看进度条与「看到 0:43 / 共 2:00」，右侧 ✕ 可单独移除一条
- 🎚️ **倍速 / 画质 / 截图 / 练习** 全部收进播放器右上角的 **⚙ 播放设置** 面板（点视频外任意处收起），
  不再在页面下方铺一排按钮：倍速 0.5x~2x（转码重启不丢，**跨会话记住**）、画质 原画/1080P/720P（手机 Wi-Fi 卡顿时降画质秒换）；
  面板里还有视频信息（分辨率/编码/时长/大小/路径）
- ▶️ **连播**：同文件夹看完自动接下一个（电视剧/教程场景），⚙ 面板可关；
  转码流进度条上有 ⏮ 上一集 / ⏭ 下一集，设置面板里也能跳
- 👁️ **已看标记**：播完自动标「已看」，⚙ 面板可手动标记/取消；卡片和播放记录页显示 ✓ 已看，重温不丢标记
- 💬 **字幕**：同目录同名 .srt/.vtt/.ass 自动加载，内封字幕自动抽取，统一转 WebVTT（缓存于 `.subscache/`）；
  ⚙ 面板可 ±0.5s 微调字幕延迟（字幕快了/慢了对不上就靠它）
- 🎯 **练习模式**：A-B 循环、逐帧步进、0.5x 慢放、画面镜像（舞蹈/教学跟练）
- 👆 转码流手势：单击暂停/播放，双击左右半区快退/快进 10 秒，长按 2 倍速
- ⌨️ 桌面键盘快捷键：空格/K 暂停、←→ 快进退 5 秒、↑↓ 音量、M 静音、F 全屏、N/P 上一集/下一集、
  0-9 跳到对应百分比、Esc 返回
- 📸 一键截图当前帧；📲 锁屏/耳机线控显示视频名（MediaSession）
- ⬆️⬇️ **上传 / 下载**：文件夹页一键上传手机里的视频（带进度、重名自动加序号）；播放页一键下载原文件
- 🗑️ **删除进回收站**：批量删除先移入系统回收站（可反悔找回），个别不支持的盘自动回退直接删
- 📲 播放中视频吸顶，边看边逛；暂停后向下滑动视频区自动收起，点「继续播放」一键回视频
- 👁️ 播放中「← 返回」2.5 秒、 「⚙ 播放设置」1.2 秒无操作自动淡出——齿轮跟浏览器自带控件条一起消失，
  返回箭头留足反应时间；暂停、点画面或移动鼠标立刻回来
- 🌗 白天/黑夜模式一键切换（首次访问自动跟随系统深浅色），手机竖屏与桌面宽屏双栏自适应
- 🔒 可选访问密码：控制台 `passwd 新密码` 开启，打开网页需先登录（`passwd off` 关闭）；
  可叠加 IP 白名单 `allow 192.168.31.0/24`，只让指定网段访问
- 📱 支持添加到主屏幕（PWA manifest，全屏打开更像 App）
- 📂 中文文件名、特殊字符、长文件名自动折叠

## 数据与缓存

| 文件/目录 | 内容 | 清理方式 |
| --- | --- | --- |
| `library.json` | 播放目录列表 | 控制台 `rm` / 网页 ✕ |
| `favorites.json` | 收藏数据 | — |

| `.transcache/` | 转码缓存（历史遗留，现转码为实时流） | 控制台 `cc` |
| `.subscache/` | 字幕 WebVTT 转换缓存 | 控制台 `cc` |
| `.warmcache.json` | 预热记录 | 控制台 `cc` |

以上均不会包含在 git 仓库/分发包里。

## 安全说明

本服务面向**可信局域网**，但以下加固已内置，即使在同一网段也不容易被滥用：

| 防护 | 说明 |
| --- | --- |
| 密码存储 | PBKDF2-HMAC-SHA256，20 万轮迭代 + 16 字节随机盐；旧版单轮 SHA256 的 `settings.json` 会在下次登录成功时自动升级 |
| 登录限速 | 同一 IP 连续 8 次失败后锁定 5 分钟（期间即使密码正确也返回 429） |
| Cookie 校验 | 精确解析 `lvpw` cookie 值并做常量时间比较，不再用子串匹配 |
| CSRF | `POST` 请求校验 `Origin`/`Referer` 与 `Host` 是否同源，跨站一律 403 |
| XSS | 登录页 `next` 参数 HTML 转义；前端动态内容统一走 `textContent` |
| 安全响应头 | `X-Content-Type-Options: nosniff`、`X-Frame-Options: SAMEORIGIN`、`Referrer-Policy: same-origin`、CSP |
| 路径穿越 | `resolve()` 用 `realpath` + `commonpath` 归一化，符号链接/junction 无法逃出播放目录 |
| 上传限制 | 只接受视频扩展名，单文件上限 32 GB |
| 错误信息 | 服务端异常只写日志，回给浏览器的是通用文案 |
| 请求体 | 超过 64 KB 的 JSON body 返回 413 并关闭连接，不会污染 keep-alive |
| IP 白名单 | 控制台 `allow` 可限定只允许指定 IP/网段访问（留空放行所有 IP） |

> 密码与 Cookie 走的是明文 HTTP，同一局域网内可被嗅探。若在宿舍/办公室等共享网络使用，建议开启密码并避免访问敏感内容；**不要**把端口映射到公网。
