🎬 局域网视频站 - 便携版使用说明（ffmpeg 全格式版）
========================================

【启动】
双击「启动视频站.bat」，会弹出黑色控制台窗口并自动打开网页。

【手机观看】
手机和电脑连同一个 Wi-Fi，用手机浏览器打开控制台窗口里显示的
「手机访问」地址，例如 http://192.168.1.100:8080/

【添加视频目录（三种方式任选）】
1. 网页首页点「＋ 添加视频目录」，输入文件夹路径
2. 在黑色控制台窗口里直接粘贴文件夹路径回车
3. 启动命令加参数：启动视频站.bat --dir D:\电影

【控制台命令】
  粘贴路径回车   添加目录（不存在会自动创建）
  ls             查看目录列表        stat   查看状态与缓存占用
  du             磁盘占用（缓存+各目录视频总量）
  search 关键词  全库搜索视频        dupes  按大小查重复视频
  qr             手机访问地址生成二维码（扫码直连，需 pip install segno）
  port 端口号    运行中换端口        rm 别名  移除目录
  cc             清空缩略图/转码/字幕缓存（浏览网页时自动重建）
  warm           预热全部目录        passwd 设置/关闭网页访问密码
  open           打开网页            q      退出        help  帮助

【上传 / 下载】
· 手机打开某个文件夹页面，点「⬆ 上传视频到这里」即可把手机里的
  视频传到电脑该文件夹（显示进度，重名自动加序号）
· 播放页点「⬇ 下载」可把当前视频的原文件下载到手机

【格式支持】
· 本包自带完整 ffmpeg：AVI / TS / WMV / MKV / MPEG4 / HEVC 等浏览器
  直接播不了的格式会自动实时转码，点开即播、无需等待
· 有 NVIDIA / Intel / AMD 显卡时自动用显卡硬编加速，更快更省电
· 转码格式的视频拖动进度条 = 从新位置重新转码，约 1~2 秒落位
· MP4/H.264 等原生格式不转码、不占 CPU，进度条秒拖

【更多播放功能】
· 播放页可调倍速（0.5x~2x）、切换画质（原画/1080P/720P，Wi-Fi 卡时用）
· 有外挂 .srt 字幕（和视频同名放一起）或视频内封字幕会自动加载
· 「🎯 练习」：A-B 循环、逐帧、0.5x 慢放、画面镜像（跟练舞蹈/教学）
· 转码流手势：双击画面左右半区快退/快进 10 秒，长按画面 2 倍速
· 「📸 截图」把当前画面存成图片；文件夹页「✓ 管理」可多选删除视频
· 首页「继续观看」和进度条在所有设备间同步（手机看一半电脑接着看）

【常见问题】
· 第一次启动弹出 Windows 防火墙询问 → 勾选「专用网络」点「允许访问」
· 手机打不开 → 确认手机和电脑在同一 Wi-Fi；检查防火墙设置
· 缩略图第一次逐个生成，之后保存在 .thumbcache 秒出；清空后自动重建
· 播放进度自动续播，并同步到服务器（progress.json），所有设备通用
· 端口被占用 → 自动换端口，以控制台窗口显示的地址为准

【说明】
· 本包自带 Python 运行时与 ffmpeg，目标电脑无需安装任何东西
· 只在局域网内可访问，不会暴露到公网
· 目录列表保存在 library.json，换电脑使用时删除它即可重新开始
· Python 与 ffmpeg 的开源许可见「第三方组件许可声明.md」
