# 🎬 新播放器预览版（player-v2）

这是主项目的一个**试验分支**：把浏览器自带的视频控件整个换成了自己写的播放器界面。
主目录的 `video_server.py` 一字未动，想用哪个版本自己选。

## 怎么跑

```bash
cd player-v2
python video_server.py
```

默认还是 8080 端口；如果主版本已经在跑，它会自动顺延到 8081（控制台会打印实际地址），
**两个版本可以同时开着对比**。

## 和主版本的区别

主版本里，能直接播的视频（mp4/webm 等）用的是**浏览器原生控件**——样子各设备不一、
比较难看；转码视频用的是老的自绘进度条。这个版本把两种模式统一成了**一套自绘播放器**：

| 部件 | 说明 |
| --- | --- |
| 进度条 | 渐变填充 + 缓冲段 + 圆形拖点，悬停变粗并弹出**时间气泡**，按下可拖拽预览 |
| 按钮行 | 播放/暂停（SVG 图标）、⏮ 上一集、⏭ 下一集、时间、音量滑杆（桌面悬停展开）、CC 字幕快捷键、画中画、⚙ 播放设置、全屏 |
| 中央大按钮 | 暂停/未起播时出现玻璃质感圆形播放键，播完变"重播" |
| 加载圈 | 视频缓冲时中央转圈（转码拖动落位期间也会出现） |
| 快进涟漪 | 双击左右半区 ±10 秒时，画面两侧弹出 «10秒 / 10秒» 涟漪动画 |
| 自动隐藏 | 播放时控制条 1.2 秒淡出、← 返回 2.5 秒淡出（节奏与主版本一致），暂停/触摸立即回来 |
| 手势 | **直连和转码通用**：单击暂停/播放、双击快进退、长按 2 倍速 |
| 全屏 | 对整个播放器容器全屏（自绘控件在全屏里继续可用）；iPhone Safari 自动退回原生全屏 |
| 音量记忆 | 音量滑杆位置存 localStorage，跨会话保持 |

倍速/画质/字幕延迟/练习模式/截图/已看/视频信息等仍然都在 ⚙ 播放设置面板里，功能与主版本一致。

## 为什么不用现成库（Plyr / Artplayer / Video.js）

调研过一轮（见对话记录）：这些库单个 150~500KB，必须整包捆绑进单文件服务器才能在**离线局域网**用；
而这个项目播放器真正的难点——转码流"拖动=重启 ffmpeg"、画质切换、A-B 循环、手势、自动隐藏——
都是自有逻辑，接进第三方播放器反而要重写事件层。自绘方案零依赖、和站点视觉一体、体积不涨。

## 满意后怎么转正

确认好用后，把 `player-v2/video_server.py` 覆盖主目录的 `video_server.py` 即可（数据文件
library.json / progress.json / settings.json 完全通用），或者直接删掉主目录旧文件。
不满意就删掉整个 `player-v2/` 文件夹，主版本毫无影响。

## 已验证

- 直连模式：自绘控制条接管（原生 controls 关闭）、CC 快捷键、进度拖拽 50%→30s 精确落位
- 转码模式：NVENC 实时转码、拖拽走 seekTrans 重启落位、上一集/下一集按清单显隐
- 悬停时间气泡（55% → 0:50）、自动隐藏节奏（1.2s/2.5s/暂停常显）
- 412px 手机视口无横向溢出，按钮全放得下
- 音量滑杆改音量 + 跨会话记忆（重载后恢复）
- Python ast + 双 script 块 node --check 通过
